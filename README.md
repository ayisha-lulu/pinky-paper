# 🎀 PINKY PAPER

A cute and simple stationery shopping website built using Python and Django.

## ✨ Features

- User Registration and Login
- Product Listing
- Product Search
- Category Filtering
- Product Details
- Shopping Cart
- Wishlist
- Checkout
- Order History
- Stock Management
- User Profile Editing

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite3
